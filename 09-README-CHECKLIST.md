# Submission README Checklist

The contest repository's `README.md` must include all of the following:

- [ ] Your full name.
- [ ] Registration number.
- [ ] Public HTTPS live link that judges can open without login.
- [ ] How to run/build the app, including commands if applicable.
- [ ] Main features completed.
- [ ] Bonus features completed (or “None”).
- [ ] Known problems/limitations honestly listed (or “None known”).
- [ ] AI tools used.
- [ ] Your most useful prompt (the prompt you actually used).
- [ ] MIT license file exists in the repository.

Also check that the README matches what the app actually does. Do not claim incomplete or untested behavior. Never include passwords, tokens, API keys, or private data.
