# Explaining the App to Judges

Prepare a short explanation based on the app you actually built. Be ready to demonstrate the core flow, switch languages, and describe one technical decision and one known limitation.

## 60–90 second outline

1. “This app helps `[organization/user]` do `[task]` by `[main benefit]`.”
2. Demonstrate the main flow: `[input/action]` → `[result]`.
3. Show the Bangla/English switch and one translated interaction.
4. Explain the key technical choice in plain language: `[browser-only approach / permitted API / browser storage]`.
5. State the limitation honestly: `[ ]`, and how you would improve it with more time.

## Check your understanding

- Can I explain where data is stored and what happens after refresh?
- Can I explain what happens if an external API fails?
- Can I identify the main component/flow and explain how it works?
- Can I explain which code came from AI and what I reviewed or corrected?
- Can I distinguish the must-have work from any bonus feature?
