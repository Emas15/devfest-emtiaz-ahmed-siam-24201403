# 90-Minute Timebox

Use T+ elapsed time from the organizer's start signal. Adjust if the official instructions change. Keep a visible timer.

| Elapsed | Goal | Required checkpoint |
|---|---|---|
| T+0–10 | Read problem, fill intake, identify main user path | Must-have list agreed with yourself; questions collected |
| T+10–15 | Ask organizer questions | Critical ambiguity resolved/recorded |
| T+15–30 | Start app and implement smallest end-to-end main flow | App starts; first coherent commit pushed before T+30 |
| T+30–50 | Complete remaining core requirements | Second commit; no broken primary flow |
| T+50–65 | Validation, useful states, Bangla/English parity | Third commit by T+60; both modes usable |
| T+60–72 | Deploy a working version | Public HTTPS link opened in fresh browser; deployment path proven |
| T+72–82 | Test required flows; fix only high-impact issues | README substantially complete; deployment reflects current eligible code |
| T+82–88 | Final fixes, final commit/push | Record commit ID; trigger/verify matching deployment |
| T+88–90 | Final link/repo/form details | Submit official form by T+90 |
| T+90–95 | Form submission only if needed | 10-mark penalty; absolutely no code/Git/deployment edits |

## Feature priority

1. Main task with a working user flow.
2. Remaining stated must-haves.
3. Correct result and understandable feedback.
4. Bangla/English completeness.
5. Public deployment and README.
6. High-value polish that does not risk the above.
7. Bonus tasks.

## Cut order when time is tight

Cut optional animation, decorative charts, extra settings, nonessential external API integration, and bonus features first. Keep the main workflow, bilingual controls/messages, deployment, README, MIT license, required commits, and submission intact.

## Time checkpoint questions

- What is the smallest version that demonstrates every required task?
- Is the public deployment already working?
- Which issue can invalidate the whole submission if ignored?
- Will this proposed change be testable and pushed before T+90?
- If not, cut it.
